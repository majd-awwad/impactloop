# ImpactLoop Vision

> Historical document — not a source of truth for the current implementation. See [docs/README.md](../../README.md) and [product/implementation-status.md](../../product/implementation-status.md) for current behavior.

> **Aspirational — product vision, not implementation status.**

ImpactLoop is a graduation software project that encourages reuse of surplus materials and helps learners build practical projects.

## Problem

Students, makers, workshops, and educational institutions often have leftover materials from projects. These materials are usually wasted or stored without being reused. At the same time, learners who want to build projects struggle to find affordable components nearby.

## Solution

ImpactLoop provides:

1. A Materials Section where suppliers can publish surplus materials.
2. A Learning Hub where learners can browse practical projects.
3. An AI Material Agent that links project components to available materials.
4. A reservation system for requesting materials.
5. Internal delivery handled by admin-created drivers.
6. Moderator/Admin review for content quality and reports.

## Main Users

- Guest
- Learner
- Supplier
- Driver
- Moderator
- Admin

## MVP Focus

The MVP focuses on:

- Authentication and roles.
- Materials browsing and publishing.
- Reservations.
- Learning Hub.
- AI material matching.
- Internal delivery.
- Basic admin and moderator tools.

## Out of Scope for MVP

- Payment subscriptions.
- Featured listings.
- Delivery partners.
- Favorite materials.
- Saved projects.
- Impact logs tables.
- Live tracking as a required feature.
