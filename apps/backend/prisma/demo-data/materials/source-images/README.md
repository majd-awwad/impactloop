# Community demo material source images

Original listing images for the 206 community demo materials.

Expected layout (from `Extracted Image Files` in `canonical-materials.csv`):

```text
source-images/
  manifest.csv
  materials/
    MAT-003_01.jpg
    MAT-005_01.jpg
    ...
```

Do not replace these with Unsplash or other stock imagery.

`*.jpg` / `*.png` under this folder are allow-listed in the root `.gitignore` so they can be committed with the demo dataset.

Public URL prefix (served by the backend): `/demo-assets/community-materials/...`
